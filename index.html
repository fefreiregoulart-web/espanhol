📘 Manual de Estudos

Revise a teoria abaixo ou clique em JOGAR no topo para praticar!

1. Pretérito Imperfecto de Indicativo

Uso: Ações habituais/rotineiras no passado, descrições e cenários de fundo.

Pessoa-AR (Hablar)-ER / -IR (Comer/Vivir)
Yohablabacomía / vivía
Túhablabascomías / vivías
Él/Ella/Ud.hablabacomía / vivía
Nosotros/ashablábamoscomíamos / vivíamos
Vosotros/ashablabaiscomíais / vivíais
Ellos/Ellas/Uds.hablabancomían / vivían

Irregulares: Ser (era, eras...), Ir (iba, ibas...), Ver (veía, veías...).

2. Pretérito Indefinido (Perfecto Simple)

Uso: Ações pontuais, finalizadas no passado em um tempo determinado (ayer, anoche).

Pessoa-AR (Hablar)-ER / -IR (Comer/Vivir)
Yohablécomí / viví
Túhablastecomiste / viviste
Él/Ella/Ud.hablócomió / vivió
Nosotros/ashablamoscomimos / vivimos
Vosotros/ashablasteiscomisteis / vivisteis
Ellos/Ellas/Uds.hablaroncomieron / vivieron

Irregulares: Ser/Ir (fui, fuiste, fue...), Hacer (hice, hiciste...), Tener (tuve, tuviste...).

3. Contraste: Indefinido vs Imperfecto

O Imperfecto descreve a ação contínua de fundo, enquanto o Indefinido representa a ação pontual que a interrompeu.

Ex: "Yo estudiaba (imperfecto) cuando el teléfono sonó (indefinido)."

4. Vocabulário das 3 Etapas

🎬 Cinema e Teatro:

  • Butaca = Poltrona
  • Taquilla = Bilheteria
  • En cartelera = Em cartaz
  • Guion / Guionista = Roteiro / Roteirista
  • Cortometraje / Largometraje = Curta-metragem / Longa-metragem
  • Cola = Fila

⚠️ Falsos Amigos & pegadinhas:

  • Pantalla (Tela de cinema/TV) ≠ Tela (Tecido)
  • Escena (Cena de filme) ≠ Cena (Jantar)
  • Subtítulo (Legenda) ≠ Leyenda (Lenda)
  • Chiste (Piada) ≠ Chisme (Fofoca)
  • Palco (Camarote) ≠ Escenario (Palco ou Cenário)
  • Campana (Sino) ≠ Sino (Conjunção: "Mas sim")

🌳 Outras palavras do caderno:

  • Gafas / Anteojos = Óculos
  • Cerdo / Puerco = Porco
  • Piso = Apartamento (América Latina: Departamento)
  • Vereda / Acera = Calçada
  • El hecho = O fato / acontecimento

5. Conjunciones

  • y -> e: Troca-se antes de palavras com som de "i" ou "hi". Ex: Padre e hijo.
  • o -> u: Troca-se antes de palavras com som de "o" ou "ho". Ex: Siete u ocho.
  • Adversativas: pero (mas/porém), sino (mas sim/pelo contrário - exclui a ideia anterior). Ex: No es grande sino pequeño.
  • Causais: porque, ya que.
